# CJM Studio — カスタマージャーニーマップ作成・共有アプリ

ユーザーフロー／ユーザーインサイトから、ペイド・オウンド・アーンドのトリプルメディア、
メディア、クリエイティブ、KPI までを **1 枚のマトリクス** で一覧化できる Web アプリです。
作成したマップは URL ひとつで共有できます。

## フォーマット

縦軸（行）は 4 つのグループにまとめた 8 行を初期構成としています。横軸（列）はフェーズです。

| グループ | 行 | 入力するもの |
| --- | --- | --- |
| ユーザー理解 | ユーザーフロー | そのフェーズでの行動・動線 |
| | ユーザーインサイト | 思考・感情・不安・期待（本音） |
| トリプルメディア | ペイド | 広告出稿・運用型／予約型メディア |
| | オウンド | 自社サイト・アプリ・LINE・メルマガ |
| | アーンド | SNS・UGC・PR・クチコミ・レビュー |
| 施策・表現 | メディア | 具体的な配信面・媒体・枠 |
| | クリエイティブ | 訴求軸・コピー・フォーマット |
| 効果測定 | KPI | 指標と目標値 |

行・列はどちらも追加／リネーム／並べ替え／削除ができます。
「行を追加」からは **感情・タッチポイント・課題・打ち手アイデア・担当体制・KGI** をワンクリックで追加できます。

## 主な機能

- **マトリクス編集** — セルにカードを追加し、6 色で分類。カードはドラッグ＆ドロップで別のセルへ移動できます
- **キーボードで連続入力** — `Enter` で次のカード、`Tab` / `Shift + Tab` で隣のフェーズへ。複数行のテキストを貼り付けると 1 行 1 カードに自動で分割されます
- **ズーム / 全体フィット** — 右下のコントロール、または `Ctrl`(`⌘`) + ホイール。フェーズが増えても一望できます
- **プレゼンモード** — フェーズを 1 つずつ全画面で送ります（`←` `→` で移動、`Esc` で終了）
- **ペルソナ / 前提** — ペルソナ、属性・背景、ユーザーのゴールをマップ上部に記録
- **リンク共有** — マップ全体を圧縮して URL に埋め込みます。サーバー不要で、共有先は閲覧専用で開きます（「自分のマップとして複製」で編集可能）
- **書き出し** — JSON（バックアップ・再取り込み）／ CSV（Excel、BOM 付き）／ 印刷・PDF 保存（A3 横）
- **テンプレート** — 空のマップ、EC / D2C の購買ジャーニー、BtoB SaaS のリード獲得
- **自動保存と元に戻す** — 編集はブラウザに自動保存。`Ctrl` / `⌘` + `Z` で取り消せます
- **テーマ** — 既定はライト。ヘッダのトグルからライト / ダーク / OS に合わせる、を選べます

## 使い方

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ に本番ビルド
npm run preview  # ビルド結果の確認
npm run test     # ユニットテスト（Vitest）
npm run typecheck
```

ビルド成果物は静的ファイルのみです（`base: './'`）。GitHub Pages や任意の静的ホスティングにそのまま配置できます。

### 操作のヒント

- セルにカーソルを合わせると「追加」が出ます
- `Enter` で確定して次のカードへ、`Tab` で隣のフェーズへ、`Shift + Enter` で改行、`Esc` で取り消し
- カードをクリックすると編集モードになり、色の変更と削除ができます
- 列・行の見出しにある「⋮」から、追加・複製・移動・削除ができます

## データの扱い

- マップはブラウザの `localStorage` にのみ保存されます。サーバーには送信されません
- 共有リンクにはマップの内容そのものが圧縮されて含まれます（`#/view/...`）。リンクを知っている人は閲覧できるため、取り扱いにご注意ください
- 内容量が多いとリンクが長くなります。目安を超えると共有ダイアログに警告を表示するので、その場合は JSON の書き出しをご利用ください
- ブラウザのデータを消すとマップも消えます。バックアップは JSON の書き出しで行ってください
- 保存データには `schemaVersion` を持たせています。データモデルを変えた場合も `src/lib/migrate.ts` が古い保存データを読み替えるため、既存のマップは開けなくなりません

## 技術構成

React 19 + TypeScript + Vite。外部 UI ライブラリは使用していません。
共有リンクの圧縮には `CompressionStream('deflate-raw')` を利用し、非対応環境では無圧縮にフォールバックします。

```
src/
├── App.tsx              ルーティング（ハッシュ）、マップの保持、元に戻す
├── types.ts             データモデルと初期行の定義
├── data/templates.ts    テンプレート
├── lib/
│   ├── actions.ts       行・列・カードの操作（純関数）※テストあり
│   ├── migrate.ts       保存データのスキーマ変換 ※テストあり
│   ├── share.ts         共有リンクのエンコード／デコード
│   ├── storage.ts       localStorage への保存・読み込み
│   ├── theme.ts         テーマ設定の保存と適用
│   └── exporters.ts     JSON / CSV の入出力
└── components/          Home / Editor / Board / Cell / CardItem / PresentMode など
```
